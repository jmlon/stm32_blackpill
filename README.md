# stm32_blackpill

Demos with the blackpill board (STM32F411CEU6 microcontroller)

Memory: 512 KB Flash and 128 KB SRAM

## push buttons
KEY  : PA0 (USER_BTN), user defined
NRST : Reset the microcontroller
BOOT0: Holding BOOT0 durint RST enters device firmware upgrade mode.


[Detailed Specs](https://stm32-base.org/boards/STM32F411CEU6-WeAct-Black-Pill-V2.0.html)
